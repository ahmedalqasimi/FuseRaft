# FuseRaft

FuseRaft enables DistributedStateful, high-performance data processing in a scalable Cluster architecture, with Auto-scaling capabilities for real-time data processing.

FuseRaft is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/FuseRaft.git`
2. `cd FuseRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure FuseRaft, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
